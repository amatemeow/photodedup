# photodedup 0.1.0

The first release of photodedup: an offline desktop app for finding and
reviewing duplicate photos and videos. This release provides a macOS installer
for Apple Silicon (M-series Macs). Intel Mac, Windows and Linux installers
are deferred to a future release.

- Review exact copies, re-saved copies, quick sequences, same-device
  look-alikes and orphan videos, with per-file choices and live matching controls.
- Browse the full scanned library and inspect full-resolution photos.
- Review possible defects detected by classical image checks.
- Move unwanted files into quarantine inside the scanned folder, restore
  individual files or batches, and resume a saved review after reopening.
- Choose Efficient, Default or Performance scan speed. Cloud-only files show
  download progress while the cloud client retrieves them.
- Bundled LGPL ffmpeg/ffprobe support HEIC photos and video without a separate
  installation. The app does not contact online services.

## Downloads

Download `photodedup_0.1.0_aarch64.dmg` for an Apple Silicon Mac.
See [installation instructions](https://github.com/amatemeow/photodedup/blob/v0.1.0/docs/INSTALL.md)
for system requirements and first-launch steps.

The app has an ad-hoc signature and is not notarised. If macOS blocks it,
open **System Settings → Privacy & Security → Open Anyway**, then confirm.
The owner installed and launched the release-candidate DMG successfully using
this workaround.
SHA-256 checksum files and GitHub build-provenance attestations accompany the
installers.

## Current limits

The initial target is trip-sized folders. Only one scan is retained at a
time. Interrupted scans restart their analysis; incremental rescans and
recognition of moved folders are deferred. Apple Photos and other detected
managed-library folders are refused to protect their databases.

The bundled AI model runtime and People/face grouping are not included in
this release. Possible defects currently uses classical measurements.
